# Rooster-leren

Een cursus Python en Cursor, opgebouwd rond één praktijkvoorbeeld: het
surveillance-rooster bij toetsen. Het doel is niet om programmeur te worden, maar
om een AI-assistent een roostertool te kunnen laten bouwen en zelf te kunnen zien
of het klopt.

## Beginnen

1. Installeer **Cursor** (via cursor.com) als je dat nog niet hebt.
2. Open deze map in Cursor: *File → Open Folder…*
3. Open **[`00-start-hier.md`](00-start-hier.md)** en lees dat eerst helemaal.

Verder heb je niets nodig. De voorbeelddata zit erbij.

## De nieuwste versie ophalen

Deze cursus wordt onderweg nog bijgewerkt: tikfouten eruit, uitleg scherper,
soms een fix. Om de laatste versie op te halen, typ je dit in de chat van Cursor:

> haal de nieuwste versie van de cursus op met git pull

Krijg je een melding over een *conflict*? Stop dan en geef een seintje. Dat
betekent dat er iets is aangepast in een bestand waar jij ook in hebt gewerkt.
Je werk raakt niet kwijt, maar het is niet iets om zelf op te lossen.

## Vastgelopen?

- Voor **uitleg**: vraag het je AI-tutor in Cursor, in **Ask-modus**. Vraag om een
  *hint*, niet om de oplossing. De ingebouwde tutorregels zorgen ervoor dat hij je
  begeleidt in plaats van het werk over te nemen.
- Voor alles wat **kapot** lijkt (een link die nergens heen gaat, een script dat
  crasht, een stap die niet klopt): geef een seintje. Dat is geen domme vraag,
  dat is een bug in de cursus.

Houd onderweg [`voortgang.md`](voortgang.md) bij. Dat is van jou, maar het helpt
enorm om te zien waar het schuurt.

# Fase 0 — De werkbank 🧰

Voordat je Python gaat schrijven, maak je je eerst thuis in **Cursor**: de plek waar
je de komende tijd werkt. Je hoeft nog niets te programmeren. Je leert wáár de knoppen
zitten, hoe je een script draait, en hoe je Cursor als tutor gebruikt in plaats van als
antwoordenmachine.

> Waarom eerst dit? Een timmerman leert eerst zijn werkbank kennen voor hij een kast
> bouwt. Als de omgeving straks vertrouwd is, kun je je aandacht volledig op het leren
> richten — niet op "waar staat die knop ook alweer?".

---

## Wat je in Fase 0 doet

| Module | Wat je leert | Duur |
|--------|--------------|------|
| `module-01-de-werkbank/` | Rondkijken in Cursor; een `.py`-bestand zelf draaien | ± 15–20 min |
| `module-02-de-vier-modi/` | De vier modi (Agent / Plan / Ask / Manueel); Ask = je tutor | ± 15–20 min |
| `module-03-checkpoints-en-diffs/` | Wijzigingen lezen en goed-/afkeuren; veilig experimenteren | ± 15 min |

Doe ze op volgorde. Elke module heeft een `les.md` waar je begint.

> ℹ️ **Let op:** de code-module (01) heeft een `opdracht.py` die je zelf draait. De
> andere twee gaan over Cursor zélf — daar is de "opdracht" een handeling *in* Cursor
> (een modus kiezen, een vraag stellen, een wijziging lezen), geen los scriptje.

---

## Voordat je begint

- Heb je Cursor nog niet? Zie **`../00-start-hier.md`** (installeren + deze map openen).
- Cursor-schermindeling ziet er per versie iets anders uit. De aanwijzingen hier
  noemen steeds het **menupad** en **waar je moet kijken**; wijkt jouw scherm af, zoek
  dan de knop met dezelfde naam. Kom je er niet uit? Vraag het in **Ask-modus** (die
  leer je in module 2).
